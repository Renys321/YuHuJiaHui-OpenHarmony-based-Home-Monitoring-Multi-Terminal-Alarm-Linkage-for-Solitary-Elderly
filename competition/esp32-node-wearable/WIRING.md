# WIRING —— 随身 SOS 按钮接线表（唯一明确版）

板子：ESP32-S3-DevKitC-1（ESP32-S3 QFN56 rev0.2 / 16MB flash / 8MB PSRAM，N16R8）
固件：`competition/esp32-node-wearable/`（UART1 接 YED M100MG-B1 4G DTU）

> 所有连线**先断电再插拔**。ESP32-S3 与 M100 **必须共地**，否则 UART 会出现随机乱码/丢包。

## 1. 求助按钮（2 脚常开按钮）

| 按钮引脚 | 接到 | 说明 |
|---|---|---|
| 一端 | **GPIO4** | 固件启用内部上拉；不需要外接上拉电阻 |
| 另一端 | **GND** | 低电平 = 按下；松开 = 高电平 |

- 按键采样 20ms、消抖 60ms；按下立即蜂鸣（<100ms）。
- 不要接到 GPIO6（16MB Flash 板的 SPI flash 脚，电平被底层驱动覆盖）。

## 2. 蜂鸣器（3 针低电流有源蜂鸣器模块，高电平触发）

| 蜂鸣器模块引脚 | 接到 | 说明 |
|---|---|---|
| **I/O**（信号） | **GPIO5** | 固件输出高电平 = 鸣响，待机输出低电平 = 静音 |
| **VCC** | **3.3V**（ESP32-S3 板 3V3） | 模块标称 3.3V 供电 |
| **GND** | **GND** | 与 ESP32 共地 |

- 本模块实测为**高电平触发**（I/O=1 响）；固件上电先输出 0，开机不鸣（无 boot beep）。
- 蜂鸣模式：SOS 3 短声循环（组间收紧）；30s 后自动静音，但事件仍未确认；之后每 30s 单短提示直到 ACK。
- 不要用 GPIO6 驱动蜂鸣器（历史故障：Flash 脚电平被覆盖导致长鸣）。

## 3. UART1 ↔ M100MG-B1（4G DTU，115200 8N1，无流控）

| ESP32-S3 | 方向 | M100MG-B1 | 说明 |
|---|---|---|---|
| **GPIO17（UART1 TX）** | → | **RXD** | ESP32 发 JSON 上行 / DTU 查询命令 |
| **GPIO18（UART1 RX）** | ← | **TXD** | 接收 MQTT 下行 ACK / DTU config 回包 |
| **GND** | ↔ | **GND** | **必须共地**，否则 UART 参考电平漂移 |

- TX/RX 必须**交叉**接（ESP32 TX → M100 RXD；ESP32 RX ← M100 TXD）。
- 115200 8N1，无硬件/软件流控；单行 JSON ≤512 字节，`\n` 结尾。
- M100 的 UART 逻辑电平需为 3.3V TTL（与本板一致）。若模块为 5V TTL，必须加电平转换/分压，
  不可把 5V 直接灌进 ESP32 GPIO。

## 4. M100 供电（独立，不可由 ESP32 3.3V 供电）

| M100 引脚 | 接到 | 说明 |
|---|---|---|
| **VCC / VIN** | **独立 5~12V 电源**（按模块标注） | 4G 发射峰值电流远超 ESP32 3.3V LDO 能力，**禁止**接 ESP32 的 3.3V/5V 排针给 M100 供电 |
| **GND** | 与 ESP32 **共地** | 独立电源负极与 ESP32 GND 必须连通 |

- ESP32-S3 由 USB 供电即可（调试/验收时）；M100 用独立 5~12V 适配器或电池。
- 两路电源**只共地、不共电源**，避免 4G 发射瞬间把 ESP32 拉复位。

## 5. 引脚占用与禁用清单

| 用途 | GPIO | 备注 |
|---|---|---|
| 求助按钮 | 4 | 内部上拉，低有效 |
| 蜂鸣器 | 5 | 高电平触发 |
| UART1 TX | 17 | → M100 RXD |
| UART1 RX | 18 | ← M100 TXD |

**禁用**：GPIO6（16MB flash 板的 SPI flash 脚）、GPIO19/20（USB）、GPIO26–37（Flash/PSRAM）。
固件在 `wearable_main.c` 里对上述禁用脚做了编译期 `#error` 检查，误配会直接构建失败。

## 6. 不上电也能确认的三件事

1. 蜂鸣器 I/O 接 GPIO5、VCC 接 3.3V、GND 接 GND（不是 5V，不是 GPIO6）。
2. 按钮一端 GPIO4、另一端 GND（内部上拉，按下导通到地）。
3. ESP32 GND、M100 GND、M100 电源负极三者连通；M100 电源独立 5~12V。
