# 最终中文告警语音 —— 电脑试听说明（烧录前）

本目录是 **2026-10-26 任务 `LOCAL-ALARM-SPEECH-FINAL`** 生成的最终语音素材与试听文件。
用户反馈“SOS 只能听到滴滴几声、听不清文字”，根因已查明为两点：

1. **旧 `sos.pcm` 根本不是人声**：它是从 `materials/sos-voice-正式.wav` 转来的 1.25 s
   正弦“滴滴”提示音（RMS/峰值 = 0.707 的正弦特征，包络为等幅方波段），所以按 SOS
   只会听到几声鸣叫。旧的 `warning.pcm` 才是人声，但文案是笼统的“监测到异常”。
2. **蜂鸣器连续响 10 秒并与语音完全重叠**：`buzzer(1)` 与 `local_voice_alarm()` 同时触发，
   人声只有约 2.8 秒，被 10 秒连续蜂鸣整段遮盖。

修复后：**先短提示音，蜂鸣器停止后再播完整中文语音**（两者不重叠），并且 5 条文案
与真实触发原因一一对应。

## 目录

| 路径 | 内容 |

| `final/*.adpcm` | 烧进固件的最终素材：IMA ADPCM 4 bit @16 kHz 单声道（8 kB/s） |
| `preview/*.wav` | 由**固件同款 ADPCM 解码器**还原成的 16 kHz WAV：与板子实际播放内容逐采样一致 |
| `preview/seq-*.wav` | 短提示音（1 kHz 方波，仅示意）+ 完整语音，用于判断“提示音是否遮盖人声” |
| `preview/preview-all-6-clips.wav` | **建议先听这个**：6 条按顺序拼接（中间 0.9 s 静音） |
| `superseded/` | 已被替换的旧素材（含那个“滴滴”正弦 `sos.pcm`），仅作证据留存，不再参与构建 |
| `MANIFEST.json` | 每条：对应触发原因、中文文案、时长、ADPCM 字节数、SHA-256、SNR、峰值/RMS |

## 与旧版的关键差异

- SOS 从“正弦提示音”改为**真人声中文**整句；播放时长约 3.5 s（含 0.2 s 前导静音）。
- 蜂鸣从“连续 10 s 且与语音重叠”改为 **SOS 3 声 / 其它 2 声，每声 200 ms、间隔 100 ms，
  结束后再等 150 ms 才播语音**；语音期间蜂鸣器保持关闭。
- 去掉了固定 `PCM ÷2` 衰减（旧代码额外损失 6 dB）。**ES8388 音量配置未改**
  （厨房 20、卫生间 30），符合“保留当前音量配置”的要求。
- 素材带 200 ms 前导 + 150 ms 尾部静音，配合固件在使能功放后等待 60 ms 再送音频，
  避免功放上电瞬态截掉第一个字。

> 说明：`seq-*.wav` 里的提示音是用 1 kHz 方波近似板载蜂鸣器，只用于判断遮盖；
> 真实蜂鸣器音色/音高由 XL9555 P0_3 板载蜂鸣器决定，不是这段 WAV。
