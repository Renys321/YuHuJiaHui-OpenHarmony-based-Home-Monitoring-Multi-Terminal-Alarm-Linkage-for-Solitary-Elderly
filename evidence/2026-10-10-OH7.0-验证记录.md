## 5. 部署注意事项（踩过的坑）

| 现象 | 原因 | 正确做法 |
|---|---|---|
| 推送二进制报 `Error opening file: text file is busy` | 目标文件正在被执行（ETXTBSY） | **先 `pkill homemon` 并确认退出，再推送**；推送到 `.new` 后 `mv -f` 原子替换，并核对板上文件大小 |
| `hdc file send` 的错误被吞掉，板上仍是旧二进制 | 用了 `\| Out-Null` 且未检查退出码 | 不要吞输出，检查 `$LASTEXITCODE`，并比对本地/板上文件大小 |
| 音频无声但日志显示 playing | 音频流被路由到 `WIRED_HEADSET` | 播放前设置 `audioRendererInfo.usage = STREAM_USAGE_ALARM` 强制扬声器 |
| 语音 Ability `LIFECYCLE_TIMEOUT` | APP 主线程被 socket 重连风暴占满 | `retryOpen` 加 `retrying` 闸门 + 重试间隔 15 秒 |
| 时间戳显示"20715 天前" | 设备时钟为 1970 时启动，基准错位 | 校准设备时钟后**重启** homemon |
