# M100MG-B1 最终配置表（随身 SOS · MQTT 双向）

> 适用：银尔达 DTU 配置工具（“4G/GPS”分组），固件 `YED_DTU4_2.0.3`。
> 本表是**最终正式值**，逐项对应工具界面字段。改完后点“**保存参数**”，按提示重启模块。
> 填写前先确认：网络通道1 的协议从当前 HTTP 切到 MQTT 后，页面字段会整体变化（以本表为准）。

## 9.1 关键坑：分组参数“自动更新”会覆盖串口写入（本次实测）

设备原“分组参数更新 = 自动更新”，因此用串口 `config,set,mqtt,...` 写入后，
**重启会被银尔达云平台的分组参数覆盖回旧值**（实测：重启后服务器地址变回 `broker.emqx.io`）。

正确做法（本次已执行）：

```text
config,get,paramsrc            -> config,paramsrc,ok,2
config,set,paramsrc,1          -> config,paramsrc,ok     # 参数源=串口，不再向云平台请求参数
config,set,mqtt,1,uart,60,47.76.70.118,1883,wearable-sos-001,wearable-sos-001,<密码>,1,1,0,0,0,eldercare/wearable/sos-001/down,eldercare/wearable/sos-001/up,0,0,0,,,0,,0,0
config,set,save                -> config,save,ok（自动重启）
```

重启后实测回读（脱敏，密码以 `<password>` 代替）：

```text
config,get,netchaninfo,1
config,netchaninfo,ok,mqtt,uart,60,47.76.70.118,1883,wearable-sos-001,wearable-sos-001,<password>,1,1,0,0,0,eldercare/wearable/sos-001/down,eldercare/wearable/sos-001/up,0,0,0,,,0,,0,0
config,get,netstatus,1 -> config,netstatus,ok,1     # 已连接
config,get,ssta       -> config,ssta,ok,4           # 网络正常且至少一个通道连上服务器
config,get,paramsrc   -> config,paramsrc,ok,1       # 串口参数源（不会被云平台覆盖）
```

> 若以后要用 WEB 平台改参数：先 `config,set,paramsrc,0`（或 2），再在平台改，否则平台改不动。
> 恢复出厂：`config,set,reset`（会清配置并重启）。
