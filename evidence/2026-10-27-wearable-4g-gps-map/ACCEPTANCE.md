# 现场验收步骤（随身 SOS · 4G · APP 地图 · ACK）

> 本文件是**用户操作手册**。每步都有“怎么做”和“成功标志”。软件注入测试与实体按键验收分开记录，不混用。

## 0. 验收前准备（一次性）

| # | 动作 | 成功标志 |
|---|---|---|
| 0.1 | 按 `WIRING.md` 接线；M100 底板只插 DC 5~12V；ESP32 用充电宝 USB 供电 | 两块板都上电，无异常发热 |
| 0.2 | 按 `M100-CONFIG.md` 配置并保存重启 | M100 NET 灯约 1000ms 慢闪、RDY/STA 常亮 |
| 0.3 | 确认 ECS 服务在线（见 `DEPLOY-ECS.md`） | 服务器上容器 healthy、1883 监听 |
| 0.4 | APP 已覆盖安装新版本（保留登录态） | 打开 APP 直接进入首页，未要求重新登录 |
| 0.5 | 把 GPS 天线放到窗外/开阔处，等 30~120 秒 | M100 的 1PPS/GPS 灯开始闪（有定位） |

## 1. 实体按键 → 蜂鸣（本地）

**操作**：按一下随身边的实体按钮。
**成功标志**：
- 立刻（<0.5 秒）听到蜂鸣器 3 短声；
- ESP32 调试串口（若接电脑）打印 `SOS 已生成 alarm=...`；
- 松手后再按不会重复生成（同一次事件未确认前只提示不新增）。

## 2. 4G 上行 → APP 出现求助（不依赖 Wi-Fi）

**操作**：保持按键触发后看手机 APP（先不要点确认）。
**成功标志**：
- 10 秒内 APP 告警列表出现一条 **随身求助 / MANUAL_SOS** 的新告警；
- 设备列表里 `随身求助` 节点显示在线；
- 该告警“待确认”状态为等待，**不是**已确认。

## 3. APP 内地图显示真实位置

**操作**：点开该条随身求助告警详情。
**成功标志**：
- 详情页内嵌地图加载出底图瓦片，并有一个位置标记；
- 地图下方/角标显示：定位状态（有效的显示“定位有效”）、定位时间、经纬度 6 位；
- 可双指/按钮缩放、可拖动、点“回到求助位置”能回到标记；
- 若位置晚于求助时间，显示“求助后更新”；若电话/网络差导致地图瓦片加载失败，仍能看到告警内容、经纬度文字与 ACK 按钮。

**用户核对**：把地图位置与实际所处位置对比，误差应在合理范围（室外 GPS 通常 <10 米；室内可能退化）。

## 4. APP 确认 → 4G/串口下行 → 设备收到回执

**操作**：在告警详情点“确认”（ACK）。
**成功标志**：
- APP 先显示“等待设备确认”（ackPending）；
- 5~15 秒内随身的蜂鸣器**停止**，ESP32 串口打印收到匹配 ACK；
- APP 随后变为 **已确认（ACKED）**，且 `acknowledgedAt` 有值；
- 若设备关机/断网：APP 保持“等待”，不会自己变成“设备已确认”。

## 5. 结束本次提示 → 再次按键产生新事件

**操作**：ACK 成功后，再按一次实体按钮。
**成功标志**：
- 蜂鸣器再次响；
- APP 出现一条**新的**随身求助告警（新的 alarmId，不是旧告警重复）；
- 旧告警保持已确认。

## 6. 无 GPS 定位时仍能求助

**操作**：把 GPS 天线放到室内/拔掉（或等冷启动未定位），按按钮。
**成功标志**：
- 蜂鸣器正常响、APP 照常出现求助；
- 地图显示“暂无定位/定位已过期”，但告警内容、经纬度状态文字与 ACK 按钮可用；
- ACK 仍能回到设备。

## 7. 短暂断网 → 恢复，不丢待发、不重复建

**操作**：触发求助后，把 M100 的 4G 天线拔掉（或把模块移到无信号处）约 30~60 秒，再装回。
**成功标志**：
- 断网期间设备持续重试（蜂鸣/串口日志可见）；
- 恢复后 APP 只出现**一条**该求助（不会两条）；
- 之后 ACK 仍能到设备。

## 8. 脱离电脑独立供电

**操作**：拔掉 ESP32 的 USB 数据线，仅用充电宝供电；M100 保持 DC 供电。
**成功标志**：
- 重复第 1~5 步全部成功（按键→蜂鸣→APP→地图→ACK→停响→再按键新事件）。

## 9. 记录与取证

| 证据 | 要求 |
|---|---|
| 现场照片/视频 | 显示按键动作、蜂鸣器、M100 灯态、手机 APP 页面同框 |
| APP 截图 | 告警列表、地图详情（含定位时间/经纬度/状态）、ACK 后的已确认状态 |
| 服务器日志 | `docker logs` 中 SOS/ACK 相关行（脱敏，不含密钥） |
| 串口日志 | ESP32 的 SOS/ACK 日志（脱敏） |
| 时间 | 记录每步实际时间（Asia/Shanghai） |

> 若某一步用“软件注入”代替实体按键（例如用 MQTT 客户端伪造设备报文），必须在报告中单独标注为 **软件注入验证**，不得写成实体按键验收。
