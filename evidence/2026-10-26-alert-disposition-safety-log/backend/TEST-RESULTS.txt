四、关键断言覆盖（均已在上述运行中通过）
---------------------------------------
纯模块（safety-log.test.js）：
- 五个 outcome 与固定展示文案；DISPOSITION_ID_RE 语法（dsp-0 / dsp-01 / 17 位等拒绝）。
- note：trim、CR/LF 归一为一个空格、200 字符接受 / 201 拒绝、C0/DEL/C1 控制字符拒绝、
  非字符串拒绝；OTHER 空说明拒绝；note 可省略。
- clientDispositionId：8-64 位字符集、拒绝 `..`、拒绝空格/斜杠/中文/非字符串。
- 请求体字段白名单：alarmId/deviceId/operator/serverTime/openid/ownerRef/household/token 等一律拒绝。
- publicDisposition 只含合同 12 个公开字段，不外泄 clientDispositionId/actor；
  outcomeLabel/operator/operatorRole/alarmCreatedAt 映射正确；serverTime=0 不被伪造为有效时间。

HTTP 合同（safety-log-api.test.js，createApiServer + MemoryStore + 随机 appAuth/tokenSecret）：
- 未认证 401、非法 token 401、非允许名单身份 403。
- 未知 alarmId 404（POST / GET / safety-logs 过滤）；非法 alarmId 格式 400。
- 首次登记 201，PublicDisposition 字段/取值精确匹配合同；同 payload 重放 200 duplicate 且不新增；
  同 clientDispositionId 改 outcome/note 409 且不覆盖；同一 clientDispositionId 在不同告警下是独立记录。
- 非法字段/长度/控制字符/OTHER 空说明/非法 clientDispositionId/空 body -> 400 invalid disposition；
  8 KiB 上限请求体 -> 400；所有失败请求不写台账、不生成命令。
- 五个 outcome 全部可登记且 outcomeLabel 正确。
- GET dispositions 按 serverTime 降序、同刻按 dispositionId 数值降序；无记录返回空数组。
- GET safety-logs：排序、limit=2/1/200、非法 limit 回退 50、alarmId 过滤、空 alarmId 不过滤、
  未知/非法 alarmId 404/400；日志均带告警展示上下文。
- 处置后 alert.status/ackPending/devices/commands 逐字节不变（JSON 对比）；ACKED 告警仍可登记处置且保持 ACKED。
- 既有 POST ack 仍返回 202 {accepted:true,status:"PENDING",commandId:"2"}，ACK 不写安全日志。
- 存储失败（ENOSPC）返回脱敏 503 {error:"storage unavailable"}，不泄露路径、不生成命令。

持久化（safety-log-persistent.test.js，临时目录 + 真实原子写）：
- v5 快照 -> safetyLogs=[]，首次处置写 schemaVersion=6 且 safetyLogs 单条字段严格白名单；
  v1..v4 同样可加载并升级到 v6。
- 跨重启记录仍在、dispositionId 单调不复用；历史空洞（dsp-1,dsp-3）后分配 dsp-4；重放幂等。
- 幂等重放 / 冲突都不写盘（atomicWriter 计数不变、文件内容不变）。
- 写盘失败：内存台账与 _maxDispositionId 回滚、文件不变；恢复后重新分配 dsp-1 并落盘。
- 损坏快照 fail-fast：重复 dispositionId / 乱序 ID / 未知 alarm / 设备不匹配 /
  重复 clientDispositionId / 未知字段(openid) / 非法 outcome / OTHER 空说明 / 未归一化 note /
  控制字符 / 超长 note / 非法 clientDispositionId / 非法 actor / 负 serverTime /
  非安全整数 ID / 超长 room / 错误 type / 非数组 safetyLogs / 超过 2000 容量。
- 容量上限 2000：第 2001 条淘汰 dsp-1，文件与重启后仍为 2000 条。
- 处置两次后 commands 与 alert JSON 完全不变；重启后命令仍 PENDING、告警仍 ALARM/ackPending=true。

隔离集成（safety-log-isolated.integration.js）：
