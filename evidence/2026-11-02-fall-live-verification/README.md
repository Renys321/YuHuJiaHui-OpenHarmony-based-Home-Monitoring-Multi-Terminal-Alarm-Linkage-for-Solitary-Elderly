## 5. 构图前提（新验收硬前提）

| 项 | 要求 | 说明 |
|---|---|---|
| 全身入镜 | 头到脚完整可见 | 下肢被切会导致髋/膝/踝不可信 |
| 距离 | 离相机 ≥ 2 m | 近景会放大透视并把髋位推到画面底部 |
| 站立帧髋部投影 | `hipY < 0.70` | 站立帧 hipY ≥0.70 视为近景/构图无效 |
| 站立帧框底 | `bboxBottom < 0.97` | 框底≈0.98–1.0 说明脚被切 |
| 方向 | 固定安装方向 | 先用站立参照物确认画面上下方向 |

服务端诊断字段（2026-11-02 收尾补丁后）：
- `/v1/state.features.bottomClipped`：框底触底；
- `/v1/state.framing`：`{bottomClipped, hipY, bboxBottom, suspectInvalid}`，
  `suspectInvalid=True` 表示当前帧构图不可用于结论；
- `/v1/state.collapse`：基线年龄、身体下沉、峰值/触底速度、证据布尔、阈值；
- `/v1/state.suspectedMode`：`horizontal` / `collapse` / null。
- `poll_state.py` 已同步这些列；**下次采集必须先看 `framingSuspectInvalid` 是否长期为 True**，
  若长期 True 则该轮数据作废。
