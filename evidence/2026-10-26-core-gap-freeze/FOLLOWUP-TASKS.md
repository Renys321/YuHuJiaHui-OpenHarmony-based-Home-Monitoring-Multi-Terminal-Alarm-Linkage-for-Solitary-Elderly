- **依赖硬件/用户动作**：门磁实物、接线、GPIO 分配与电平确认（用户/现场）；确定装哪一房间；烧录授权。
- **验收口径**：真实开/合各一次 → 上报 `open` 翻转、`lastOpenTs` 严格前进；APP 显示"最近开启 x 前"且能区分"未知/无记录"；断线后不伪造；重启不丢记录（或如实清零）。仅源码/单测不算。
- **本轮是否已开始**：**否**。代码骨架存在但 `lastOpenTs` 硬编码 0（`esp32-node/main/node_main.c:904`），部署节点门磁全部禁用。

### F-02 P0 便携无线 SOS 接入（对应 A4）

- **目标**：把"便携/随身求助"从固定按键扩展为真实无线按钮（433M 接收或 BLE），并与 MANUAL_SOS→上报→ACK 闭环一致；手机端远程 SOS 若纳入范围需另立接口。
- **依赖硬件/用户动作**：无线按钮与接收模块/BLE 配对硬件；用户确认佩戴/触发方式；APP 远程 SOS 需求由用户选择是否做。
- **验收口径**：随身按钮真实按压 → 新 `MANUAL_SOS`（不重复）→ 202 → 设备 ACKED → APP"设备已确认"；含距离/电池/误触测试。
- **本轮是否已开始**：**否**。当前仅卫生间固定实体 SOS 真实闭环（2026-10-22）；DAYU 只有 433M 接收脚配置未验收；手机悬浮远程 SOS 明确未开放。

### F-03 P1 真实阈值异常触发验收（对应 A5）

- **目标**：用真实传感器/受控环境触发 CLIMATE 越界与 NO_MOTION，验证告警优先级、ACK、重新武装；GAS/SMOKE 需先标定再决定是否启用阈值。
- **依赖硬件/用户动作**：用户授权触发一次受控异常（温湿度越界/长时间无活动）；气体标定需传感器与标准气体/专业标定，且用户确认是否启用。
- **验收口径**：真实越界 → CLIMATE/NO_MOTION 告警 → 上报 → APP 显示待确认 → ACK → 设备 ACKED；无告警风暴；GAS/SMOKE 在未标定前保持禁用且文案不误导。
- **本轮是否已开始**：**否**。逻辑与主机测试在（54/54 LOCAL），真实越界未触发；GAS/SMOKE 阈值 4096=禁用。
