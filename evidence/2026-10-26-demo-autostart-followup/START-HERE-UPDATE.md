# START-HERE 更新（followup）

入口和日常操作不变，新增三点：

## 页面 ms 的含义

页面：

```text
检测到人体 · 4909 帧 · 248 ms
```

`248 ms` 是正式应用侧的**Surface 抓取 + JPEG 编码 + HTTP POST 往返 + JSON 解析**，不是推理耗时，也不是 summary 的 `inferMs`。不要把这个数当作推理性能。

## 三节点

全屋在线 X/Y 按页面实际显示；离线无线节点可保持 1/1、2/2 等，不影响本地相机/推理，不要把离线节点写成全部在线。

## 停止/退出

- 正式页“暂停监护”会停止推理；点“恢复监护”恢复。
- 看护窗口 `S` 停止自动看护，`R` 恢复，`Q` 退出看护窗口；关闭看护窗口不会主动停止 P0/应用/推理。
- 明确停止拍摄：在正式页点“暂停监护”；这也会被看护器尊重，不会自动反向拉起。

## 冷启动（待用户执行）

正常重启电脑后只需：

1. Explorer 双击 `<WORKSPACE>\competition\materials\start-demo-all.cmd`；
2. 若自动出现 P0 窗口，隐藏输入一次 `INGEST_KEY`；
3. 不需要再启动相机/推理或补恢复命令。

详见 `COLD-START-HANDOFF.md`。
