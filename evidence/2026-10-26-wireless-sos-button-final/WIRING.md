# 接线说明（2026-10-26 / v4）

本文件只描述**本次相关**的三块板接线；不重复历史全项目接线审计。

## 1. 随身求助按钮板（COM8，ESP32-S3，MAC `30:30:f9:08:76:84`）

| 器件 | 接线 | 电平/说明 |
|---|---|---|
| 轻触按钮 | 一脚 → **GPIO4**，另一脚 → **GND** | 内部上拉，**低电平 = 按下**；固件消抖确认 2 次（≈200 ms） |
| 有源蜂鸣器（3 针） | `I/O` → **GPIO5**；`VCC` → 3.3V；`GND` → GND | **高电平鸣响**，`off = 0` 静音（当前板上固件就是这个配置） |
| ~~GPIO6~~ | **严禁复用** | 该板 GPIO6 是 Flash 引脚 |
| 供电 | **待用户改为独立移动电源/电池** | 当前依赖 USB 数据线，属于未验收项 |

固件实测日志（`verify/com8-net-verify.log` / 历史日志）：
```
gpio: GPIO[4]| InputEn: 1| OutputEn: 0| Pullup: 1| ...     ← 按钮
gpio: GPIO[5]| InputEn: 0| OutputEn: 1| ...                ← 蜂鸣器
```

> 若实物接线与上表不符（例如蜂鸣器实际接在别的脚、或模块是低电平触发），**先停烧录、由用户确认实物**，不得凭日志假定接线已正确。

## 2. 厨房固定板（COM5，MAC `50:78:7d:16:ed:60`，`esp32-kitchen` / 厨房）

| 功能 | 引脚 | 备注 |
|---|---|---|
| 板载 KEY0 求助 | XL9555 **P1_7**（I2C 0x20） | 低电平按下；固件会先把该脚改成输入方向 |
| 蜂鸣器 | XL9555 **P0_3** | 与语音不重叠：先 N 声短鸣，再播语音 |
| LED | **GPIO1**，**低电平亮** | 本次镜像保持不变 |
| AHT20 | SDA **GPIO4** / SCL **GPIO5** | |
| MQ-2 | ADC1_CH5（**GPIO6**） | |
| MQ-5 | ADC1_CH6（**GPIO7**） | 必须带 `kitchen-voice-rewire` 叠加，否则与 I2S 冲突编译报错 |
| I2S（ES8388） | MCLK **GPIO3** / LRCK **GPIO9** / BCLK **GPIO46** / DOUT **GPIO10** | 音量寄存器 30（≈0 dB） |
| 门磁 | 未启用（`DOOR_GPIO=-1`） | 厨房门磁由门磁工程另行规划 |

## 3. 卫生间固定板（COM4，MAC `14:c1:9f:42:dd:b4`，`esp32-bath` / 卫生间）

| 功能 | 引脚 | 备注 |
|---|---|---|
| PIR | **GPIO36** | |
| SOS 按键 | **GPIO15** | 内部上拉，低电平按下 |
| 蜂鸣器 | XL9555 **P0_3** | |
| LED | **GPIO1**，低电平亮 | 三合一镜像恢复；当前板上门磁固件为 `-1`（灯不亮） |
| AHT20 | SDA **GPIO4** / SCL **GPIO5** | |
| 门磁（干簧管，常开型 NO） | 一端 **GPIO14**（内部上拉），另一端 **GND** | 磁铁靠近=闭合=低；远离=断开=高。`DOOR_OPEN_LEVEL=1` |
| I2S（ES8388） | 同厨房：3 / 9 / 46 / 10 | 三合一镜像恢复语音；当前门磁固件未启用语音 |
| MQ-2 / MQ-5 | 未启用 | |

> **注意**：卫生间目前运行的是门磁候选固件（无语音、无 LED）。要参与本次播报，需要烧 §5.4 的三合一镜像（`42F24D5F…`），该镜像同时保留门磁 GPIO14。
